01

The six, as given

Every ratio on this page is computed from WCAG relative luminance. The verdict column is what decides a color's role — FAIL means it cannot carry text on that ground.

02

Where each color sits

A palette is six pigments. A theme is seven roles. The mapping is not arbitrary: contrast decides it, and the two themes invert moss and mist.

03

What breaks, rendered

Not hypotheticals — these are the three combinations a naive application of the palette produces, drawn as they would ship.

Moss text on basalt
moss / charcoal1.53unreadable

Moss is 1.53:1 on the dark ground — the single most likely mistake, because “primary brand color on the background” is the default instinct. On dark, moss is a surface, never ink.

Golden text on mist
golden / mist1.88unreadable

Golden hour is a highlight, not an ink. Light mode needs #8a6320 (4.76:1) for text and keeps #dfa84a for fills, rules and glow.

Lichen text on mist
lichen / mist1.99unreadable

Lichen is a dark-ground support color. Light mode steps it down to #5a6a53 (5.11:1) — same hue family, same quietness, legible.

05

Porting it into the app

The theme already exposes these token names — the swap is a rewrite of :root and [data-theme="light"] in app/globals.css, plus a rename of --brass-* into cedar/golden.

app/globals.css — dark
:root / [data-theme="dark"] {
  --bg-0: #25282a;   /* basalt ground */
  --bg-1: #2b3330;   --bg-2: #39443f;   --bg-3: #43514a;
  --line: rgba(163,177,155,.16);   --line-strong: rgba(163,177,155,.30);
  --ink: #eef1f2;      /* mist, 13.07:1 */
  --ink-dim: #a3b19b;  /* lichen,  6.58:1 */
  --accent: #b87355;   /* cedar,  UI/large 3.97:1 */
  --golden: #dfa84a;   /* 6.95:1 */
}

[data-theme="light"] {
  --bg-0: #eef1f2;   /* overcast ground */
  --ink: #25282a;    /* 13.07:1 */
  --accent: #8f5138; /* cedar-ink 5.44:1 */
  --ink-dim: #5a6a53; /* lichen-ink 5.11:1 */
  --golden: #8a6320; /* golden-ink 4.76:1 */
}
→Keep the names, change the values. Every app CSS module resolves var(--bg-1)/var(--brass) — a token rewrite re-themes all four apps with no component edits, the same way the Workroom pass did it.
→The espresso→basalt shift is cool. The Workroom is warm (espresso #13100c, brass). This is cold-damp (basalt #25282a, moss). The grain overlay, the Fraunces display and the mono data lines all still work — only the temperature changes.
→Groove's instrument tokens have to be re-cast by hand. The groovebox declares its own --inst-* set and must stay dark under light mode; nothing here covers it.
→Five test gates will need real updates: app/globals.test.ts locks the token values and the retired hexes, tests/workroom-namespace.test.ts asserts both themes declare the full colour set and that no retired hex (#0a0a0a, #171717, #ffffff) appears in app code, and 5.7's e2e reads the computed rgb() of the ground for dark and light. A palette swap is a spec-level change, not a CSS drive-by.
→Read this page in both directions. Toggle the button — the same markup and the same six pigments, two temperatures. The dark direction is “wet forest floor at dusk”; the light one is “the ten minutes the sun gets through.”

# Feature 1.5: Deals table

**Phase:** 1 — CRM
**Status:** completed
**Estimated effort:** 3–4 hours
**Depends on:** 1.4
**Blocks:** 1.6, 1.7

## Goal

Users can add, search, edit, and delete deals with stage, value (USD), probability, close date, organization, and primary contact.

## Scope

Include:
- Deals table (TanStack Table)
- Search by deal name (and org/contact names, matching the reference)
- Add / edit / delete
- Default probability from `STAGE_PROBABILITY` when stage is set and probability omitted
- Explicit probability on the form is kept until stage changes (stage change rebase is 1.6 `moveDeal`; form stage change should rebase the same way)
- New deal `boardOrder` = end of that stage column
- Organization detail lists its deals
- Tenant-scoped actions + unit tests

Exclude (for now):
- Pipeline board and drag-and-drop (1.6)
- Dashboard (1.8)

## Spec

Stages in order: New, Qualified, Proposal, Negotiation, Won, Lost.
Value is USD number. Single currency.

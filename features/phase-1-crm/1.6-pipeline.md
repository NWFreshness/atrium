## Goal

The pipeline is six columns of deal cards. Dragging a card to another stage persists, rebases probability, and updates column totals.

## Scope

Include:
- `/crm/pipeline` board: New → Qualified → Proposal → Negotiation → Won → Lost
- `@hello-pangea/dnd` (same as the reference)
- Cards show name, value, expected value, probability
- Column + header totals: open pipeline value and expected revenue (`value * probability / 100`)
- Open = not Won and not Lost; Won/Lost values leave open-pipeline totals
- `moveDeal(tenantId, id, stage, index)`: drop into a column at index; renumber `boardOrder` in that column
- Changing column rebases probability to `STAGE_PROBABILITY[stage]`; same-column reorder does not
- Persist after refresh; Deals table matches
- Unit tests for move including Won and Lost; expected totals
- Keyboard drag in tests (Space / arrows / Space) if e2e is added here; otherwise unit tests suffice and 1.9 covers a smoke

Exclude (for now):
- Configurable stages
- Dashboard charts
- Pixel-identical reference CSS (stage colors may follow reference `STAGE_COLOR`: gray, blue, purple, amber, green, red)

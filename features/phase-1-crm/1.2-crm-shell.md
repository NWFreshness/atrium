# Feature 1.2: CRM shell and subnav

**Phase:** 1 — CRM
**Status:** pending
**Estimated effort:** 2–3 hours
**Depends on:** 1.1
**Blocks:** 1.3, 1.4, 1.5, 1.6, 1.8

## Goal

`/crm` is a real app shell with five sections. Shared Atrium nav stays; CRM CSS does not leak into other apps.

## Scope

Include:
- CRM layout under `app/(authenticated)/crm/` with subnav: Dashboard, Organizations, Contacts, Deals, Pipeline
- Routes: `/crm` (dashboard landing), `/crm/organizations`, `/crm/contacts`, `/crm/deals`, `/crm/pipeline`
- Current section marked (amber accent, glyphs/icons — not extra brand colors)
- CRM-scoped stylesheet (`crm-` prefix or a CSS module imported only from the CRM layout)
- Placeholder body copy per section until later features fill them (“Organizations” heading is enough)
- Atrium nav still shows CRM as current on all `/crm/*`

Exclude (for now):
- Tables, forms, pipeline board, dashboard charts
- TanStack
- Pixel-identical Bench CSS
- Importing CRM CSS in the root layout

## Files to create

- `app/(authenticated)/crm/layout.tsx`
- `app/(authenticated)/crm/organizations/page.tsx`
- `app/(authenticated)/crm/contacts/page.tsx`
- `app/(authenticated)/crm/deals/page.tsx`
- `app/(authenticated)/crm/pipeline/page.tsx`
- `components/crm/crm-subnav.tsx`
- `components/crm/crm-subnav.module.css` or `app/(authenticated)/crm/crm.css`

## Files to modify

- `app/(authenticated)/crm/page.tsx` — dashboard landing (placeholder ok)
- Do not put CRM styles in `app/globals.css` or `atrium-nav` classes

## Acceptance criteria

1. [ ] Logged-in `/crm` shows five subnav links to the routes above
2. [ ] Each route renders (not 404); dashboard is `/crm`
3. [ ] Current section is marked; Atrium strip still present
4. [ ] Unauthenticated `/crm` still redirects `/login`
5. [ ] CRM class names that style the subnav are `crm-` prefixed (or CSS-module locals sourced from CRM-only files)
6. [ ] `npm test` and `npm run build` pass
7. [ ] No regressions in launcher/nav/theme e2e

## Implementation notes

- Bench sidebar lives inside `/crm`; Atrium home is the product nav above. Do not duplicate Home/Space/Rolodex/Groove inside CRM subnav.
- Look-and-feel later (1.8/1.9). Shell can be plain.
- Register CRM resetter import here if 1.1 did not already hook it into a server entry.

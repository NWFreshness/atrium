# Feature 1.3: Organizations table and detail

**Phase:** 1 — CRM
**Status:** pending
**Estimated effort:** 4–5 hours
**Depends on:** 1.1, 1.2
**Blocks:** 1.4, 1.5

## Goal

Users can add, search, edit, and delete organizations. Detail shows the org. Changes persist.

## Scope

Include:
- `@tanstack/react-table` for the organizations list (first TanStack use; Table only)
- Search by name / website / industry
- Add / edit via modal (`role="dialog"`); delete via confirm
- Detail at `/crm/organizations/[id]` — name, website, industry, notes (contacts/deals lists wait for 1.4/1.5)
- Server actions using `requireTenant()`; never take `tenantId` from the client
- Missing/other-tenant id → not found, not another tenant’s row
- Unit tests for list/search/create/update/delete scoped by tenant

Exclude (for now):
- Pagination, import/export, tags, custom fields
- TanStack Query / Router
- Contact and deal counts on the table (add in 1.4/1.5 if cheap; not required here)

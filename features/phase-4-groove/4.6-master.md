# Feature 4.6: Master filter, sweep, pump, FX, and scope

**Phase:** 4 — Groove
**Status:** completed
**Estimated effort:** 5–6 hours
**Depends on:** 4.5
**Blocks:** 4.7

## Goal

The bottom strip is the performance master: DJ filter, sweep, sidechain, send FX, volume, and a spectrum with the live filter curve.

## Scope

Include:

- Master panel from `MASTER_GROUPS` + hero FILTER knob (`FILTER_SPEC`)
- Filter: left of centre resonant lowpass, right highpass, centre OPEN; RESO; BITE
- Sweep: depth, length OFF/1/2/4/8/16 bars, shape rise/fall/triangle/sine; segmented meter
- Sidechain: pump depth + release; ducks bass/pads/lead on kick; drums untouched
- Send FX: delay in 16ths, repeats, tone, reverb, glue
- Volume
- Scope: analyser spectrum + `filterGainAt` overlay
- Port Bench `filter.ts` mapping already in 4.1 — audio graph and readout must agree

Exclude (for now):

- Audition / live apply polish that belongs in 4.7 if not already wired
- Visual screenshot diffs
- Pixel-identical Bench scope styling

## Files to create

- `components/groove/master.tsx` + test
- `components/groove/scope.tsx` + test

## Files to modify

- `lib/groove/audio/master.ts` — complete DJ filter, pump, delay, reverb, analyser
- `lib/groove/audio/engine.ts` — expose `analyser`, `filterMacro`, `sweepPhase`
- Groove page — mount Master

## Spec

Port Bench `Master.tsx`, `Scope.tsx`, and `audio/master.ts`. LATE ORBIT’s eight-bar triangle sweep must be representable (patch D already stores those params in 4.1).

Live filter readout while playing uses `engine.filterMacro`; when stopped, the patch’s `master.filter`.

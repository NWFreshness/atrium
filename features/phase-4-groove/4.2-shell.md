# Feature 4.2: Groove shell and hardware layout

**Phase:** 4 — Groove
**Status:** completed
**Estimated effort:** 3 hours
**Depends on:** 4.1
**Blocks:** 4.3, 4.4

## Goal

`/groove` is a real instrument shell: transport row, four unit regions, master strip. Shared Atrium nav stays; Groove CSS does not leak into other apps.

## Scope

Include:

- Groove layout under `app/(authenticated)/groove/`
- Route: `/groove` only (no subnav)
- Named regions for RHYTHM, BASS, PADS, LEAD (placeholder bodies ok)
- Transport row placeholder (PLAY copy is enough)
- Master strip placeholder
- Groove-scoped stylesheet (`groove-` prefix or a CSS module imported only from Groove files)
- Hardware-style desk, desktop 16:9. Panel may stay dark; define `[data-theme="light"]` overrides if needed. Do not write `atrium.theme`
- Atrium nav still shows Groove as current on `/groove`

Exclude (for now):

- Working sequencers, knobs, Web Audio (4.3+)
- Pixel-identical reference `styles.css`
- Importing Groove CSS in the root layout
- Forcing the whole product into dark theme

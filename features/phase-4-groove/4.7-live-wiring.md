# Feature 4.7: Live wiring (audition, applyParams, patch-during-play)

**Phase:** 4 — Groove
**Status:** pending
**Estimated effort:** 3–4 hours
**Depends on:** 4.5, 4.6
**Blocks:** 4.8

## Goal

The instrument is live: tweaks and patch changes apply while the clock runs; clicking a step auditions the sound; the engine reads current state every tick.

## Scope

Include:

- `EngineState` `{ patch, mutes, volume }` held in a ref the engine reads each tick (Bench `stateRef`)
- `applyParams` when patch / mutes / volume change
- Patch switch during playback (no stop required)
- `auditionDrum` / `auditionNote` on step paint when the new value is on
- Filter sweep phase continues across patch changes via `absStep` (Bench: never wraps)
- Keyboard and transport still work while playing

Exclude (for now):

- Persistence
- MIDI
- Playwright (4.8)
- Claiming CI can hear the mix

## Files to create

- None required beyond tests for the edit helpers if 4.4 did not extract them

## Files to modify

- Groove client App (port remaining Bench `App.tsx`)
- `lib/groove/audio/engine.ts` — `applyParams`, audition methods, `getState` callback

## Spec

Port Bench `App.tsx` effects:

1. Construct Engine once; `onStep = setCurrent`
2. Write `stateRef.current` after render
3. `applyParams(stateRef.current)` when patch/mutes/volume change
4. Drum step handler: edit pattern; if `audition && value > 0`, `engine.auditionDrum(lane, value === 2)`

## Acceptance criteria

1. [ ] Changing a knob while PLAY is on does not require STOP to hear the new value (applyParams)
2. [ ] Switching to BASALT while playing keeps the transport in STOP-copy (still playing) and changes BPM
3. [ ] Clicking a drum step on auditions that voice
4. [ ] Engine is created only in the browser (`typeof window` / client component)
5. [ ] `npm test` and `npm run build` pass
6. [ ] No Groove database usage

## Implementation notes

- Autoplay: audition also needs a running/resumed context — resume on first gesture if needed.
- Do not add an audio-graph introspection hook for tests (Bench: deliberate non-goal).

# Feature 4.5: Audio engine (clock, drums, synths)

**Phase:** 4 — Groove
**Status:** completed
**Estimated effort:** 6–8 hours
**Depends on:** 4.1, 4.4
**Blocks:** 4.6, 4.7

## Goal

Play starts a Web Audio lookahead clock. Drums, bass, pads, and lead fire from the current patch. The playhead LED is driven by the same transport. No samples, no extra audio libraries.

## Scope

Include:

- `Engine` with `AudioContext({ latencyHint: "interactive" })`
- Lookahead: 25 ms timer, schedule 0.12 s ahead (reference)
- `triggerDrum` for six lanes; `MonoSynth` bass/lead; `PadSynth` pads
- Master bus stub sufficient to hear units (full DJ filter UI is 4.6; the graph may already include a filter node)
- `resume()` / `start()` / `stop()`; `onStep` updates the LED strip
- Playhead `-1` when stopped
- Pure helpers (`gapToNext`, `sweepValue`) unit-tested without AudioContext
- PLAY on the transport calls `engine.resume()` then start/stop
- Import engine only from `"use client"` files

Exclude (for now):

- Master panel knobs, scope canvas, sweep meters (4.6)
- Step audition on click (4.7)
- Tone.js, sample files, asserting timbre in CI

## Files to create

- `lib/groove/audio/engine.ts`

## Files to modify

- Groove client page — construct Engine, wire PLAY, `onStep` → LED `current`
- Do not import `lib/groove/audio/*` from a Server Component

## Spec

Port the reference implementation's `web/src/groove/audio/{engine,drums,synths,master}.ts`. Prefer the reference if a comment and the graph disagree.

Scheduler: `nextGridTime` on the audio clock so UI jank does not drift timing. Swing delays even steps.

Mute: a muted unit is not scheduled.

Headless CI has no audio device — do not fail tests because `AudioContext` is missing in Node. Domain helpers stay in Vitest; the engine class is exercised in 4.8.

## Implementation notes

- Browser autoplay: `resume()` must run from the PLAY click (user gesture).
- Driving Groove with a visible browser plays sound out loud. Stop the transport before walking away.
- neon-http / Drizzle are irrelevant. Do not add Groove tables.

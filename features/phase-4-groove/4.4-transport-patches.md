# Feature 4.4: Transport, patches, mute, keyboard, revert

**Phase:** 4 — Groove
**Status:** pending
**Estimated effort:** 3–4 hours
**Depends on:** 4.3
**Blocks:** 4.5, 4.8

## Goal

The deck is editable: play/stop UI, tempo, swing, four factory patches, per-unit mute, Space and 1–4 keys, revert after tweaks. Playhead may stay at `-1` until 4.5 owns the clock.

## Scope

Include:

- Transport: PLAY/STOP button, BPM, swing, patch buttons named from factory patches, REVERT when dirty
- Patch A loaded at startup
- Switching patches replaces the whole snapshot (sounds, patterns, tempo, swing, master params)
- MUTE on each unit toggles a muted class on the region
- Keyboard: Space play/stop (preventDefault), 1–4 select patches; ignore when target is an input
- `clonePatch` on load and on revert
- Unit tests for patch switch / mute / revert (no AudioContext)

Exclude (for now):

- Starting `AudioContext` (4.5)
- Master filter UI (4.6)
- Audition on step click (4.7)
- Asserting sound

## Files to create

- `components/groove/transport.tsx` + test
- Optional `lib/groove/patch-edit.ts` for `setUnitParam` / `setDrumStep` / `setNoteStep` (keep App.tsx thin)

## Files to modify

- Groove page / shell — hold `patches`, `index`, `mutes`, `playing`
- Units receive mute and edit callbacks

## Spec

Port Bench `Transport.tsx` and the state helpers in `App.tsx` (`setUnitParam`, `setDrumStep`, `setNoteStep`). Do not construct `Engine` yet.

Patch button accessible names must include the Bench names (at least BASALT) so 4.8 can click `/BASALT/`.

PLAY/STOP is `getByRole("button", { name: /(PLAY|STOP)/ })`.

## Acceptance criteria

1. [ ] `/groove` boots on patch A; transport shows PLAY
2. [ ] Patch buttons switch tempo copy (BASALT ≠ NEON RIVIERA BPM)
3. [ ] MUTE on RHYTHM toggles a muted class; second click clears it
4. [ ] Space toggles PLAY/STOP copy; keys 1–4 change patch
5. [ ] Tweaking a control then REVERT restores factory patch A
6. [ ] No `AudioContext` / engine start in this feature
7. [ ] `npm test` and `npm run build` pass

## Implementation notes

- Dirty check: `JSON.stringify(patch) !== JSON.stringify(PATCHES[index])` is what Bench does — fine here.
- Playhead LEDs stay off (`current = -1`) until 4.5.

# Feature 3.7: Important dates and calendar

**Phase:** 3 — Rolodex
**Status:** pending
**Estimated effort:** 4–5 hours
**Depends on:** 3.3
**Blocks:** 3.8, 3.9

## Goal

People can have recurring dates. The Calendar section is a month grid of those dates. Arithmetic matches Bench, including 29 February.

## Scope

Include:

- Add/edit/delete important dates on the person page: birthday, anniversary, work anniversary, child’s birthday, other — with or without year
- Age and “turns N this year” when year is known; milestone when that age ends in 0
- `/rolodex/calendar` month grid; prev/next including year boundary
- Dates land on the correct day; 29 Feb shows on 28 Feb in common years
- Clicking a calendar entry opens that person
- Upcoming dates listed on the person page
- Unit tests for next occurrence, leap day, year boundary, milestone

Exclude (for now):

- Gift-idea surfacing (3.8)
- Today’s 30-day upcoming panel (3.9)
- Syncing with an external calendar

## Spec

Port Bench `importantDates.ts` / `web/src/rolodex/dates.ts`. Server helpers are the authority; do not fork a second algorithm on the client if the page can use the server result.

`react-calendar` is allowed if it stays Rolodex-scoped. If used, override its light-theme nav buttons so dark mode does not show a white block (Bench pitfall). Otherwise a small custom grid is fine — do not add the library unless it earns its weight.

## Acceptance criteria

1. [ ] A person can have one or more important dates, with or without a year; they appear on their page
2. [ ] Year known → correct age; milestone when the age this year ends in 0
3. [ ] Calendar month grid; navigating across a year boundary works
4. [ ] Clicking a date opens that person
5. [ ] 29 Feb is shown on 28 Feb in a common year and does not crash
6. [ ] Unit tests for recurring-date arithmetic
7. [ ] `npm test` and `npm run build` pass
8. [ ] No regressions in 3.3

# Feature 3.2: Rolodex shell and subnav

**Phase:** 3 — Rolodex
**Status:** completed
**Estimated effort:** 2–3 hours
**Depends on:** 3.1
**Blocks:** 3.3, 3.5, 3.9

## Goal

`/rolodex` is a real app shell with five sections. Shared Atrium nav stays; Rolodex CSS does not leak into other apps.

## Scope

Include:

- Rolodex layout under `app/(authenticated)/rolodex/` with subnav: Today, People, Circles, Calendar, Timeline
- Routes: `/rolodex` (Today landing), `/rolodex/people`, `/rolodex/circles`, `/rolodex/calendar`, `/rolodex/timeline`
- Current section marked (amber accent, glyphs/icons — not extra brand colors)
- Rolodex-scoped stylesheet (`rolodex-` prefix or a CSS module imported only from Rolodex files)
- Placeholder body copy per section until later features fill them (“People” heading is enough)
- Atrium nav still shows Rolodex as current on all `/rolodex/*`

Exclude (for now):

- Tables, forms, board, calendar grid, charts
- TanStack
- Pixel-identical reference CSS
- Importing Rolodex CSS in the root layout

## Files to create

- `app/(authenticated)/rolodex/layout.tsx`
- `app/(authenticated)/rolodex/people/page.tsx`
- `app/(authenticated)/rolodex/circles/page.tsx`
- `app/(authenticated)/rolodex/calendar/page.tsx`
- `app/(authenticated)/rolodex/timeline/page.tsx`
- `components/rolodex/rolodex-subnav.tsx`
- `components/rolodex/rolodex-subnav.module.css` or `app/(authenticated)/rolodex/rolodex.css`

## Files to modify

- `app/(authenticated)/rolodex/page.tsx` — Today landing (placeholder ok)
- Do not put Rolodex styles in `app/globals.css` or `atrium-nav` classes

## Acceptance criteria

1. [x] Logged-in `/rolodex` shows five subnav links to the routes above
2. [x] Each route renders (not 404); Today is `/rolodex`
3. [x] Current section is marked; Atrium strip still present
4. [x] Unauthenticated `/rolodex` still redirects `/login`
5. [x] Rolodex class names that style the subnav are `rolodex-` prefixed (or CSS-module locals sourced from Rolodex-only files)
6. [x] `npm test` and `npm run build` pass
7. [x] No regressions in launcher/nav/theme e2e

## Implementation notes

- The reference sidebar lives inside `/rolodex`; Atrium home is the product nav above. Do not duplicate Home/CRM/Space/Groove inside Rolodex subnav.
- Look-and-feel later (3.9/3.10). Shell can be plain.
- Palette when you do add color: `#ecad0a`, `#209dd7`, `#753991` + grays. No background gradients, purple backgrounds, gradient buttons, or single-side accent borders.

# Feature 3.9: Today dashboard

**Phase:** 3 — Rolodex
**Status:** pending
**Estimated effort:** 5–6 hours
**Depends on:** 3.5, 3.6, 3.7
**Blocks:** 3.10

## Goal

`/rolodex` is an at-a-glance Today whose figures match the underlying tenant data. Who to contact is the most prominent thing on the page.

## Scope

Include:

- Today as `/rolodex` landing
- Who to contact: due and overdue, most overdue first; one-click log an interaction from the list
- Birthdays and important dates in the next 30 days
- Reminders due and overdue
- Recent activity feed
- Two charts via `recharts` with `isAnimationActive={false}`: interactions logged per month; people per circle with overdue counts
- Aggregations in `lib/rolodex/` (unit-tested), not inside chart components
- Empty panels keep written empty states — no blank or collapsed panels
- Tenant-scoped: demo sees demo numbers; owner sees only owner data

Exclude (for now):

- Extra analytics, custom date ranges, export
- Chart animation
- Pixel-identical Bench CSS; Today hero may be a dark panel in both themes (Bench `--panel`) — keep tokens local to Rolodex

## Files to create

- `lib/rolodex/dashboard.ts` — whoToContact, upcomingDates, dueReminders, recentActivity, interactionsPerMonth, peoplePerCircle
- `lib/rolodex/dashboard.test.ts`
- `components/rolodex/today-dashboard.tsx`
- `components/rolodex/today-charts.tsx`

## Files to modify

- `app/(authenticated)/rolodex/page.tsx`

## Spec

Follow Bench `docs/rolodex/IMPLEMENTATION.md` and dashboard route:

- Who to contact uses `computeStatus`; exclude `off` and `snoozed`; sort most overdue first
- Upcoming dates: next occurrence within 30 days (29 Feb rule from 3.1/3.7)
- Logging from Today removes that person from who-to-contact on refresh
- Chart series must match the same dataset the lists use

Who to contact is above and larger than everything else.

## Acceptance criteria

1. [ ] Today shows who to contact, upcoming dates, due/overdue reminders, recent activity, and two charts
2. [ ] Figures match unit-tested aggregations on the same dataset
3. [ ] Logging an interaction from Today removes them from who-to-contact on refresh
4. [ ] Marking a reminder done, adding news, or changing circle is reflected on refresh
5. [ ] Empty tenant still shows written empty states for every panel
6. [ ] Owner and demo dashboards do not mix rows
7. [ ] `npm test` and `npm run build` pass
8. [ ] No regressions in 3.5–3.7

## Implementation notes

- Initials on every person in the who-to-contact list.

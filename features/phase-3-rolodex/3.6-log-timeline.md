# Feature 3.6: Interactions, facts, news, reminders, and Timeline

**Phase:** 3 — Rolodex
**Status:** completed
**Estimated effort:** 5–6 hours
**Depends on:** 3.3
**Blocks:** 3.9

## Goal

From a person’s page you can log contact, remember facts, record news, and set reminders. Last contacted and status recalculate from the newest interaction. Timeline shows everything across everyone.

## Scope

Include:

- Person page: log interaction (call, message, email, met, other) with date + notes
- Person timeline newest first (interactions; news; completed reminders)
- Adding a fact (compact list, distinct from freeform notes)
- Adding news with a date; newest becomes `latestNews` on the person page and People table
- Reminder with due date and done / not-done; `doneAt` set when marked done
- `/rolodex/timeline`: all people, newest first; filter by person and by type (`interaction` | `news` | `reminder_done`)
- Logging an interaction updates last contacted and status on the next read (no extra column write)
- Unit tests for log, last-contacted derivation, reminder toggle, tenant isolation

Exclude (for now):

- Today one-click log (3.9)
- Gifts and connections (3.8)
- Important dates UI (3.7)

Timeline entry shape (reference):

```ts

//    interactionType, date, text }
```

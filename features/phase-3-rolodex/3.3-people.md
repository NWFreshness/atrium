# Feature 3.3: People table and person page

**Phase:** 3 — Rolodex
**Status:** completed
**Estimated effort:** 4–5 hours
**Depends on:** 3.1, 3.2
**Blocks:** 3.4, 3.5, 3.6, 3.7, 3.8

## Goal

Users can add, search, filter, edit, and delete people. A person page shows their details. Changes persist. Initials stand in for photos.

## Scope

Include:

- `@tanstack/react-table` for the People list (Table only; already in the repo)
- Columns: initials, name, company, circle, last contacted, latest news, check-in status
- Search by name / company / email
- Filter by circle and by tag
- Add / edit via modal (`role="dialog"`); delete via confirm
- Detail at `/rolodex/people/[id]` — fields from 3.1 (notes, how met, tags, cadence override, check-ins off, snooze). Timeline/facts/news/reminders/gifts/dates/connections wait for later features; a heading placeholder is enough
- Initials on a flat color derived from the name (table + detail)
- Server actions using `requireTenant()`; never take `tenantId` from the client
- Missing/other-tenant id → not found, not another tenant’s row
- Owner empty list is a written empty state
- Unit tests for list/search/filter/create/update/delete scoped by tenant

Exclude (for now):

- Pagination, CSV/vCard import (3.4), photo upload
- TanStack Query / Router
- Logging interactions from the person page (3.6)
- Circles board (3.5)

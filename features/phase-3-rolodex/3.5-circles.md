# Feature 3.5: Circles board, cadence, and snooze

**Phase:** 3 — Rolodex
**Status:** completed
**Estimated effort:** 4–5 hours
**Depends on:** 3.3
**Blocks:** 3.9

## Goal

People sit in four circle columns. Dragging a card changes circle. Cadence, check-ins off, and snooze change derived status everywhere the person appears.

## Scope

Include:

- `/rolodex/circles` board: Inner → Close → Wider → Distant
- `@hello-pangea/dnd` (already in the repo; same as CRM pipeline)
- Cards: initials, name, last contacted, check-in status
- Column header: count of people and count of overdue
- Drag between columns persists circle; People table and person page match after refresh
- Per-person cadence override (days), check-ins off, snooze until a date — on the person page (and/or a small card action). Changing these updates status
- Board fills horizontal space; column lists scroll; no page-level horizontal scrollbar unless necessary
- Unit tests for `movePersonCircle` and status after override / off / snooze

Exclude (for now):

- User-defined circles
- Dashboard Today (3.9)
- Pixel-identical reference CSS

## Goal

Space tables exist, every query is tenant-scoped from the session, demo data can be seeded and wiped without touching the owner tenant.

## Scope

Include:

- Drizzle tables: `pages`, `blocks`, `properties`, `propertyOptions`, `rowValues`, `views` — each with `tenantId`
- UUID text ids (match users/tenants)
- Constants: page types (`page` | `database` | `row`), block types, property types, view kinds
- Query helpers that take `tenantId` as a required argument (never from the client)
- Dual-path memory repo + Drizzle; optional filters as a trailing `opts` after `repo`
- Demo seed for the demo tenant only; owner tenant stays empty
- `registerDemoResetter` that deletes that tenant’s Space rows then re-seeds demo
- Unit tests without `DATABASE_URL`

Exclude (for now):

- Space UI (2.2+)
- Slash menu, drag-and-drop, TanStack, search palette
- Changing a property’s type after creation, relations/rollups/formulas
- File/image uploads, trash, version history, import/export
- Rolodex / Groove tables

## Spec

Postgres field shapes (camelCase, like CRM):

```ts
// pages: id, tenantId, parentId, type, title, icon, position, createdAt, updatedAt
//   type: page | database | row
//   parentId → pages.id onDelete cascade (null = top-level)
//   database rows are pages with type=row whose parent is the database
// blocks: id, tenantId, pageId, type, content (jsonb), position
//   pageId → pages.id cascade
// properties: id, tenantId, databaseId, name, type, position
//   type: text | number | select | multi_select | date | checkbox | url (fixed at create)
// propertyOptions: id, tenantId, propertyId, name, color, position
// rowValues: tenantId, rowId, propertyId, value (jsonb); PK (rowId, propertyId)
// views: tenantId, databaseId, kind (table | board | list), config (jsonb); PK (databaseId, kind)
```

`tenantId` → `tenants.id` restrict. Deleting a page cascades nested pages, blocks, properties, options, row values, views.

Block types (eleven): `paragraph`, `heading1`, `heading2`, `heading3`, `bulleted_list`, `numbered_list`, `todo`, `quote`, `divider`, `code`, `callout`.

Demo seed: nested page tree with icons (several levels). Later features extend seed (blocks, databases, views). Owner: none. Seed is idempotent (skip insert when that tenant already has Space pages). Reset still deletes then seeds.

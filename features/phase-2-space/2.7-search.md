# Feature 2.7: Quick-find search

**Phase:** 2 — Space
**Status:** completed
**Estimated effort:** 3–4 hours
**Depends on:** 2.5
**Blocks:** 2.8

## Goal

A quick-find searches page, database, and row titles as you type and jumps to the chosen result.

## Scope

Include:
- Visible control + keyboard shortcut (document the shortcut in the UI; reference-style cmd/ctrl+K is fine)
- Live filter of titles (pages, databases, rows) for the session tenant only
- Choosing a result navigates to `/space/[id]`
- Unit tests for match + tenant isolation

Exclude (for now):
- Full-text search inside block content
- Theme work (already 0.4)
- Pixel-identical palette modal

## Files to create

- `lib/space/search.ts`
- `lib/space/search.test.ts`
- `lib/space/search-actions.ts`
- `components/space/quick-find.tsx`

## Files to modify

- Space shell / layout to host the control

## Spec

```ts
// searchPages(tenantId, q, repo?): { id, title, type }[]
// empty q → [] or recent titles; pick one and test it
```

Do not search other tenants. Ignore client `tenantId`.

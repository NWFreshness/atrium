# Feature 2.8: Space Playwright smoke

**Phase:** 2 — Space
**Status:** pending
**Estimated effort:** 3–4 hours
**Depends on:** 2.6, 2.7
**Blocks:** nothing

## Goal

CI can prove a logged-in demo user can walk Space without 404s or mixed-tenant data.

## Scope

Include:
- `e2e/space.spec.ts`
- Unauthenticated `/space` → `/login`
- Demo login → `/space` shows seeded sidebar titles
- Open a page; see blocks or a database table
- One write path: create or rename a page (or edit a block) and still see it after reload
- Owner login: Space does not show demo seed titles
- CI already runs `npx playwright test`; do not hardcode only `login.spec.ts`

Exclude (for now):
- Full Bench exploratory / adversarial editor suite
- Visual screenshot diffs
- Rolodex / Groove e2e
- Mouse kanban e2e unless already cheap (unit tests cover move)

## Files to create

- `e2e/space.spec.ts`

## Files to modify

- None required in CI if it already runs the full Playwright suite
- Optional `data-testid`s if role/label is not enough

## Acceptance criteria

1. [ ] Playwright Space smoke passes locally with `.env` secrets
2. [ ] Unauthenticated `/space` redirects to login
3. [ ] Demo sees seed Space titles; owner does not
4. [ ] One write persists across reload
5. [ ] Existing login/launcher/theme/CRM e2e still pass
6. [ ] `npm test` and `npm run build` still pass
7. [ ] No regressions in 2.6–2.7

- Prefer role/label selectors.

- Do not print `.env` values.

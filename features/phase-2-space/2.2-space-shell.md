# Feature 2.2: Space shell and sidebar frame

**Phase:** 2 — Space
**Status:** pending
**Estimated effort:** 3 hours
**Depends on:** 2.1
**Blocks:** 2.3, 2.4, 2.5, 2.8

## Goal

`/space` is a real app shell: sidebar column + page column. Shared Atrium nav stays; Space CSS does not leak into other apps.

## Scope

Include:
- Space layout under `app/(authenticated)/space/`
- Routes: `/space` (empty or “pick a page”), `/space/[id]` (placeholder page body until 2.3/2.4)
- Sidebar frame (tree filled in 2.3); page header area (title/icon placeholders ok)
- Current page marked when an id is in the URL
- Space-scoped stylesheet (`space-` prefix or a CSS module imported only from the Space layout)
- Atrium nav still shows Space as current on all `/space/*`

Exclude (for now):
- Create/rename/delete pages (2.3)
- Block editor (2.4)
- Databases (2.5)
- Search palette (2.7)
- Pixel-identical Bench CSS
- Importing Space CSS in the root layout

## Files to create

- `app/(authenticated)/space/layout.tsx`
- `app/(authenticated)/space/[id]/page.tsx`
- `components/space/space-shell.tsx`
- `components/space/space-shell.module.css`

## Files to modify

- `app/(authenticated)/space/page.tsx` — landing inside the shell
- Do not put Space styles in `app/globals.css` or `atrium-nav` classes

## Acceptance criteria

1. [ ] Logged-in `/space` shows sidebar + page columns (not the old “Coming soon” only)
2. [ ] `/space/[id]` renders (not 404) even if the page body is a placeholder
3. [ ] Unauthenticated `/space` still redirects `/login`
4. [ ] Atrium strip still present; Space is current on `/space` and `/space/[id]`
5. [ ] Space class names that style the shell are `space-` prefixed (or CSS-module locals from Space-only files)
6. [ ] `npm test` and `npm run build` pass; build lists `/space` and `/space/[id]`
7. [ ] No regressions in launcher/nav/theme e2e

## Implementation notes

- Bench sidebar lives inside `/space`; Atrium home is the product nav above. Do not duplicate Home/CRM/Rolodex/Groove inside Space.
- `/space` may redirect to the first tree page later (2.3). Placeholder landing is enough here.
- Register Space resetter import here if 2.1 did not already hook it into a server entry.

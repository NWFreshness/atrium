# Feature 2.6: Board, list, filters, and sorts

**Phase:** 2 — Space
**Status:** completed
**Estimated effort:** 1 day
**Depends on:** 2.5
**Blocks:** 2.8

## Goal

Each database switches table / board / list over the same rows. Filters and sort persist per view. Board drag changes the grouping select.

## Scope

Include:
- View switcher on a database page
- Board: group by a chosen select property; drag card to another column updates that value; reorder within column; optional column reorder via header grip
- List: compact title + at least one property
- Filters (AND): text contains; select is / is not; checkbox; date before / after
- Sort by any property, asc/desc
- Persist filters, sort, grouping in `views.config` per `(databaseId, kind)`
- Pure `viewLogic` in `lib/space/` with unit tests — no aggregation math in React
- Extend seed so at least one database has a meaningful board, one filtered view, one sorted view

Exclude (for now):
- Search (2.7)
- Pixel-identical Bench CSS
- Chart animation / extra analytics

# Feature 2.5: Databases and table view

**Phase:** 2 — Space
**Status:** completed
**Estimated effort:** 1 day
**Depends on:** 2.3, 2.4
**Blocks:** 2.6, 2.7, 2.8

## Goal

A database is a page in the sidebar. Rows have typed properties. The table view edits cells in place. A row opens as a page (properties + blocks).

## Scope

Include:
- Create a database (sidebar); it is `pages.type = database`
- Seven property types: text, number, select, multi-select, date, checkbox, URL
- Add / rename / remove properties; type is fixed at create
- Select and multi-select options: user-defined, colored, shared across rows of that database
- Table view: add/delete rows, in-place cell editors that fit the type
- Row page: `/space/[id]` with properties on top, block editor below (reuse 2.4)
- TanStack Table v9 allowed (`useTable` + `tableFeatures` + `createColumnHelper` + `table.FlexRender`)
- Extend demo seed with at least two databases and realistic rows
- Unit tests for row/property CRUD and tenant isolation

Exclude (for now):
- Board and list views, filters, sorts (2.6)
- Relations, rollups, formulas
- Databases embedded inside ordinary pages
- Changing a property type after create

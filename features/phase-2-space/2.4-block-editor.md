# Feature 2.4: Block editor

**Phase:** 2 — Space
**Status:** completed
**Estimated effort:** 1–2 days
**Depends on:** 2.3
**Blocks:** 2.5, 2.8

## Goal

A page is a stack of blocks edited in place. Changes save automatically. Slash menu inserts types. Blocks reorder by drag.

## Scope

Include:
- Eleven block types, visibly distinct: paragraph, heading 1–3, bulleted list, numbered list, to-do (checkbox persists), quote, divider, code, callout
- Autosave (no save button)
- Enter starts a new block below; Backspace at the start of an empty block removes it
- `/` slash menu: filterable, keyboard (arrows + Enter) and mouse
- Drag to reorder within the page; order persists
- Session actions + unit tests for create/update/reorder/delete blocks
- Extend demo seed so at least one page uses every block type

Exclude (for now):
- Databases (2.5)
- Embeds, images, files
- Collaborative cursors / undo across sessions
- Pixel-identical Bench editor CSS

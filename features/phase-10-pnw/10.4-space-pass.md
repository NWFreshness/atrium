# Feature 10.4: Space pass

**Phase:** 10 — PNW (redesign)
**Status:** specced
**Estimated effort:** 3–4 hours
**Depends on:** 10.1, 10.2
**Blocks:** 10.7

## Goal

Space becomes the quiet reading room of the PNW theme: a mist-grey sidebar on basalt, Outfit page titles, Archivo prose at a comfortable measure, mono for every property value. Block, row, view, and drag behaviour is untouched.

## Scope

Include:

- `components/space/space-shell.module.css` sidebar restyle: pages tree, QuickFind field, New page / New database controls, footer count; brass current-page marker; hover-revealed row actions stay opacity-based so Playwright can click them
- `components/space/editor.module.css` + `editor.tsx`: block surfaces on the PNW tokens (text, list, todo, quote, code, callout, divider), dragdot handles in `--ink-faint`, the slash menu on `--bg-2` with a `--brass` selected row, the mono `space-editor-meta` line
- `components/space/space-icons.tsx`: doc / database / row glyphs inherit `currentColor`; no emoji anywhere
- Database surfaces: `database-table.tsx` (TanStack table cells, header at `--text-label`), `database-views.tsx` (table/list switcher + filter chips), `board-view.tsx` (dnd-kit columns) — presentation only
- Body/prose typography: `--measure` 68ch for the editor body, `--text-body` 16px/1.6, `--text-h1`/`--text-h2` for page titles, mono for property values and dates
- Empty states ("Pick a page") restyled, copy unchanged

Exclude (for now):

- Block editor behaviour: autosave, Enter/Backspace semantics, `/` menu filtering, todo toggling, `@hello-pangea/dnd` reorder
- Database property types, view persistence, filters/sorts logic, QuickFind matching (`lib/space/*` untouched)
- The page tree's structure, ordering, or `type: row` hiding

## Files to create

- `components/space/space-pnw.test.ts` — extends `space-pass.test.ts`: PNW token names, no emoji, sidebar action-affordance rule (opacity, not `display:none`), golden reserved for the current page marker

## Files to modify

- `components/space/space-shell.module.css`, `editor.module.css`, `editor.tsx` (markup class hooks only), `sidebar-tree.tsx`, `database-table.module.css`, `database-views.module.css`, `board-view.module.css`

## Spec

1. The sidebar is the one place in Space with a raised surface: `--bg-1` against the page's `--bg-0` on dark, `--bg-1` against mist on light. The tree's current page is marked with a 2px golden inset rule and `--ink`; every other link is `--ink-dim`.
2. Row actions (rename/delete) appear on hover/focus via `opacity`, never `display` — 5.4 shipped a `display:none` first cut that broke the Playwright click; this feature must not reintroduce it.
3. Editor prose uses the body scale, not the display face: Archivo 16px/1.6 at 68ch. Headings inside a page use `--text-h2`/`--text-h3` in Outfit. Code blocks and inline code use Geist Mono at `--text-data`.
4. Database cells: numbers right-aligned with `tabular-nums`; dates and select values in mono; the table header row uses `--text-label` in `--ink-faint`. Row hover is `--bg-2`; there is no zebra striping.
5. The board's drag state uses `--brass` for the drop indicator and a cool panel shadow for the lifted card; no second accent appears during a drag.
6. Filters and sorts keep their chips on `--bg-1` with `--line-strong` borders; the selected chip is `--brass` text with a `--brass-soft` background (the one highlight in that bar).
7. All existing behaviour is frozen: same server actions, same autosave debounce, same optimistic updates, same accessible names.

## Implementation notes

- Space has the most CSS surface area of the four apps; land the token swap first and the refinements second, so a failing gate points at one change.
- The measured type argument matters most here: Archivo's narrower advance means the 68ch measure holds at typical panel widths without wrapping early; if a prose column measures under ~50ch at 1280px, widen the panel rather than shrinking type.
- `space-pass.test.ts` from 5.4 asserts the SVG-glyph rule and the add-block affordance; keep those assertions when extending it.

# Feature 10.5: Rolodex pass

**Phase:** 10 — PNW (redesign)
**Status:** specced
**Estimated effort:** 3–4 hours
**Depends on:** 10.1, 10.2
**Blocks:** 10.7

## Goal

Rolodex is where the PNW palette earns its keep: mist and lichen for people, cedar for anyone overdue, golden only for the one thing to do next. People, cadence, import, timeline, date, and gift behaviour is untouched.

## Scope

Include:

- `components/rolodex/today.module.css` + `today-dashboard.tsx`: four KPI tiles (overdue `--clay-ink`, due `--brass`, dates `--moss`, reminders `--slate`), who-to-contact rows as cards with initials avatars, cadence line in mono, due chips, `Log contact` as the single primary action
- `components/rolodex/today-charts.tsx`: the four series literals move to the PNW data palette (`#8fae83` → `#a3b19b`, `#cd7258` → `#e0a488`, `#8b9fc2` unchanged, `#a88fc0` → `#b9ab93`), keeping the comment that ties each series to its chip/tile colour
- `components/rolodex/people.module.css`, `circles-board.module.css` (four circle accents stepping through lichen → moss → cedar → golden), `calendar-month.module.css` (today marker in `--brass`, month grid on tokens)
- `components/rolodex/rolodex-subnav.tsx` → shared `atrium-subnav`, golden active
- All five section pages wrap headings in `atrium-pagetitle` with a mono sub
- Import dialog, timeline, person page panels restyled on tokens; `rolodex-status-*` classes preserved (existing gates and e2e reference them)

Exclude (for now):

- Any cadence, snooze, gift, connection, or date arithmetic (`lib/rolodex/*` untouched)
- Import mapping logic, the `PERSON_FIELDS` catalog, and the 9.5 import limits
- The circles board's `movePersonCircle` behaviour
- Photo/avatar upload (still initials only, by design)

## Files to create

## Spec

1. Cadence state is the palette's job: overdue = `--clay-ink`, due within seven days = `--brass`, on cadence = `--moss`, snoozed/off = `--slate`. The same mapping must appear in the KPI tiles, the rows, and the charts on that screen — `today-charts.tsx`'s existing comment already promises this; keep it true.
2. The who-to-contact list keeps its density: at least eight rows visible at 800px viewport height. In the current build ~32 rows accumulate from e2e runs, so the list must not grow its row height to fill the card.
3. Initials avatars take `--clay` (not `--clay-ink`) as a fill with mist text in both themes: `#b87355` with `#eef1f2` is 4.55:1 — one of the few places the raw cedar fill carries text, and it is measured, not assumed.
4. `Log contact` is the only primary button on Today, and therefore the only golden fill on that screen; at most one row may take a golden chip (the soonest due) and the rest step down to `--moss`/`--clay-ink`.
5. The calendar's today marker is a `--brass` ring, not a filled golden cell (a filled cell competes with the overdue tone on the same screen). Month grid lines use `--line`; the 29-Feb → 28 handling is untouched.
6. Dates and counts are mono with `tabular-nums`; person names are Archivo at body size; section headings are Outfit.
7. Behaviour frozen: same filters, same search fields, same accessible names used by `e2e/rolodex.spec.ts` (`People`, `Log contact`, person links).

## Acceptance criteria

2. [ ] Overdue / due / on-cadence / snoozed use the clay / golden / moss / slate mapping consistently across tiles, rows, and charts
3. [ ] The four circle accents follow the lichen → moss → cedar → golden order; board drag still works
4. [ ] Only one golden fill (`Log contact`) and at most one golden chip per Today render
5. [ ] `rolodex-status-*` classes still exist and the initials-avatar contrast holds (4.55:1 cedar-on-mist)
6. [ ] `e2e/rolodex.spec.ts` passes (4 tests) and the Rolodex subnav link-walk in `e2e/workroom.spec.ts` stays green

## Implementation notes

- The Rolodex e2e is the flakiest suite (heavy `/rolodex` render on a loaded dev DB). Raise per-test timeouts if needed and use a demo Reset if accumulated e2e rows push seed people below the fold — both are documented in the skill, and both are environment issues rather than regressions.
- Keep the "at least eight rows" rule in the spec's own terms: the row height is fixed by avatar + two lines of text, and padding is 12px, as in the study.

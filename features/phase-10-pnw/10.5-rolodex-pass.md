## Goal

Rolodex is where the PNW palette earns its keep: mist and lichen for people, cedar for anyone overdue, golden only for the one thing to do next. People, cadence, import, timeline, date, and gift behaviour is untouched.

## Scope

Include:

- `components/rolodex/today.module.css` + `today-dashboard.tsx`: four KPI tiles (overdue `--clay-ink`, due `--brass`, dates `--moss`, reminders `--slate`), who-to-contact rows as cards with initials avatars, cadence line in mono, due chips, `Log contact` as the single primary action
- `components/rolodex/today-charts.tsx`: the four series literals move to the PNW data palette (`#8fae83` → `#a3b19b`, `#cd7258` → `#e0a488`, `#8b9fc2` unchanged, `#a88fc0` → `#b9ab93`), keeping the comment that ties each series to its chip/tile colour
- `components/rolodex/people.module.css`, `circles-board.module.css` (four circle accents stepping through lichen → moss → cedar → golden), `calendar-month.module.css` (today marker in `--brass`, month grid on tokens)
- `components/rolodex/rolodex-subnav.tsx` → shared `atrium-subnav`, golden active
- All five section pages wrap headings in `atrium-pagetitle` with a mono sub
- Import dialog, timeline, person page panels restyled on tokens; `rolodex-status-*` classes preserved (existing gates and e2e reference them)

Exclude (for now):

- Any cadence, snooze, gift, connection, or date arithmetic (`lib/rolodex/*` untouched)
- Import mapping logic, the `PERSON_FIELDS` catalog, and the 9.5 import limits
- The circles board's `movePersonCircle` behaviour
- Photo/avatar upload (still initials only, by design)

## Files to create

## Spec

1. Cadence state is the palette's job: overdue = `--clay-ink`, due within seven days = `--brass`, on cadence = `--moss`, snoozed/off = `--slate`. The same mapping must appear in the KPI tiles, the rows, and the charts on that screen — `today-charts.tsx`'s existing comment already promises this; keep it true.
2. The who-to-contact list keeps its density: at least eight rows visible at 800px viewport height. In the current build ~32 rows accumulate from e2e runs, so the list must not grow its row height to fill the card.
3. Initials avatars take `--clay-ink` as the fill with `--bg-0` text (charcoal on `#e0a488` = 6.95:1 dark, mist on `#8f5138` = 5.44:1 light). **Corrected during implementation:** this spec first claimed raw cedar `--clay` with mist text was 4.55:1; measured, that pair is **3.29:1** (and charcoal on raw cedar is 3.97:1), so neither carries a 12px initial. The gate now computes the ratio from the shipped tokens instead of restating it.
4. `Log contact` is the only primary button on Today, and therefore the only golden fill on that screen; at most one row may take a golden chip (the soonest due) and the rest step down to `--moss`/`--clay-ink`.
5. The calendar's today marker is a `--brass` ring, not a filled golden cell (a filled cell competes with the overdue tone on the same screen). Month grid lines use `--line`; the 29-Feb → 28 handling is untouched.
6. Dates and counts are mono with `tabular-nums`; person names are Archivo at body size; section headings are Outfit.
7. Behaviour frozen: same filters, same search fields, same accessible names used by `e2e/rolodex.spec.ts` (`People`, `Log contact`, person links).

## Shipped notes

Rolodex re-skinned; cadence, snooze, gifts, connections, dates, import mapping, `PERSON_FIELDS`, and the circles drag are untouched. Cadence state is one mapping across tiles, rows, and charts: overdue `--clay-ink`, due within a week `--brass`, on cadence `--moss`, snoozed/off `--slate`. `Log contact` is the only golden fill on Today — only the first row takes the shared primary, and only the soonest due row takes a golden chip; the rest step down. Initials avatars are a uniform `--clay-ink` fill with `--bg-0` initials. The calendar's today marker is a `--brass` ring (new `today` prop threaded from the page's existing `todayISO()` — no new date arithmetic). `rolodex-status-*` classes are preserved.

Verified by the controller: `env -u DATABASE_URL npm test` **777 passed** (110 files), build exit 0.

**A wrong number in this spec was caught and fixed here.** §3 claimed mist on raw cedar = 4.55:1 and told the avatar to fill with `--clay`. Measured, `#b87355` carries mist at **3.29:1** and charcoal at **3.97:1** — both fail AA for a 12px initial. The avatar now fills with `--clay-ink` and takes `--bg-0` text (6.95:1 dark, 5.44:1 light), and the gate computes that ratio from `app/globals.css` rather than restating it in prose. The probe was run in both directions: reverting the fill to `#b87355` fails the gate, restoring it passes. An independent reviewer re-derived all four ratios (6.948 / 5.438 / 3.291 / 3.971) and confirmed the correction is exact, not overstated.

**Spec-compliance review found three more things, all fixed in this commit:**
1. **The retracted 4.55:1 claim was still shipped in CSS.** `people.module.css` described raw cedar with mist text as 4.55:1 three lines above the rule that does the opposite. The comment now states the measured pair and says the earlier number was wrong — a comment the gate cannot police, which is why it was worth reading.
2. **The Timeline's Filter button was off the token layer.** It carried no `className`, and the Workroom-era `.rolodex-search button { padding }` rule this pass deleted was its only styling — so it silently lost its padding. It now takes the shared `atrium-btn`, and a gate scans real markup for classless buttons (allowing the legitimate `.rolodex-row-actions button` descendant pattern). Probed: removing the class fails the gate.
3. **The gate's retired-pair probe was weaker than the claim made for it.** It hardcoded `#b87355`/`#eef1f2` instead of reading `--clay`/`--ink` from the shipped tokens, and one assertion (`not.toContain("background: #b87355")`) could never fire. Both now read from `globals.css`, so a token change cannot make the probe lie.

Limits: no browser run (AC1 render, AC3 drag, AC6 e2e are source-verified only). §1's "one mapping across tiles, rows, and charts" is an overclaim as shipped: overdue and due are consistent, but on-cadence is lichen `#a3b19b` in the chart while the tiles use `--moss` (which is 1.53:1 and can never be ink, so §1's literal mapping is unsatisfiable as written). Tiles 3 and 4 are dates and reminders, not cadence states. §2's "at least eight rows at 800px" has no test and the row padding went 9px → 12px, so it is unverified and harder to hold. `colorFromName` in `lib/rolodex/initials.ts` now has no component consumer — the uniform fill replaced the per-name colour, so the avatar's `style={{ background }}` is gone; the function keeps only its own unit test. Deleting it is a follow-up decision, not this feature's.

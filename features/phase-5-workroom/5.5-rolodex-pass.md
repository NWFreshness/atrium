# Feature 5.5: Rolodex Worldroom pass

**Phase:** 5 — Workroom (redesign)
**Status:** completed
**Estimated effort:** 4–6 hours
**Depends on:** 5.2
**Blocks:** 5.7

## Goal

Rolodex — Today, People, Circles, Calendar, Timeline — re-skinned with the Workroom direction, centred on the Today dashboard's cadence cards.

## Scope

Include:

- **Today** (`/rolodex`, `today.module.css`) per `rolodex.html`:
  - `pagetitle` (Fraunces h1 + mono sub) and the SVG-glyph `subnav` shared classes
  - KPI row of four tiles (overdue to contact, due within a week, dates in 30 days, reminders due) with the clay/brass/moss top-accent rules and Fraunces figures
  - "Who to contact" list: `contact-row` cards — `avatar` initials in a per-circle color (`--av`), name + cadence sub-line, a due `chip` (clay = overdue, brass = due soon, moss = in window, faint = far), and a `Log contact` button
  - "Dates in 30 days" and recent-activity panels on Today dressed identically
- **People** (`people.module.css`): TanStack table, add/edit dialog, circle/tag filters, and initials avatars in the shared table/chip/avatar style
- **Circles** (`circles-board.module.css`): the four-column `@hello-pangea/dnd` board with warm column headers (counts + overdue), deal-style cards
- **Calendar** (`calendar-month.module.css`) and **Timeline**: month grid, days, and the timeline rows adopt the paper/chip/mono treatments
- **Person page** and importer screens: panel/card/field styles consistent with the rest

Exclude (for now):

- Any people data, cadence, snooze, import, timeline, or date behaviour; all `rolodex-` helpers stay
- Restyling CRM / Space / Groove (5.3, 5.4, 5.6)
- Renaming any `rolodex-` CSS module/class

## Files to modify

- `components/rolodex/today.module.css` (+ `today` markup), `rolodex-subnav.module.css` (+ icons), `people.module.css`, `circles-board.module.css`, `calendar-month.module.css`
- Person-page, import, and timeline component CSS as needed (keep the `rolodex-status-*` classes the screens still interpolate)

## Spec

1. Today's who-to-contact list keeps its ordering (most overdue first) and the one-click contact log; only the rows change — do not reimplement the "who to contact" computation (3.9 stays).
2. Avatar color derives from the person's circle/name as in 3.3 (initials-only v1 — no photos), mapped through the warm `--av` palette.
3. KPI tiles map 1:1 to the 3.9 aggregations (recomputed with the dashboard `today` anchor, per the util); the empty states keep their written copy.
4. `rolodex-status-*` classes must remain when other screens/style depend on them — add workroom rules after existing selectors, never replace a sibling block.
5. Shared button/card/field/chip/avatar styles come from `atrium-`; `rolodex-` modules only add app-local overrides.

## Acceptance criteria

# Feature 0.1: Next.js scaffold + AGENTS.md + CI

**Phase:** 0 — Atrium platform
**Status:** completed
**Estimated effort:** 3–4 hours
**Depends on:** nothing
**Blocks:** 0.2, 0.3, 0.4, 0.5

## Goal

A running Next.js App Router app on this repo, with agent rules, unit tests, and GitHub Actions, and no auth or database yet.

## Scope

Include:
- Next.js App Router at the repo root (no `src/` directory)
- TypeScript strict
- ESLint + Prettier
- Vitest wired so `npm test` runs
- `AGENTS.md` with Atrium rules from the design
- `.env.example` with names only (no secrets)
- GitHub Actions: `npm test` and `npm run build` on push/PR
- Public placeholder at `/` (name Atrium, one sentence). Login and apps come later.

Exclude (for now):
- Tailwind, shadcn, TanStack
- Auth.js, Drizzle, Neon
- Playwright
- Real launcher / nav strip
- Vercel production deploy (config must not block `next build`)

## Files to create

- `package.json`, `package-lock.json`, `tsconfig.json`, `next.config.ts`
- `eslint.config.mjs` (or project default) and `.prettierrc`
- `app/layout.tsx`, `app/page.tsx`, `app/globals.css`
- `vitest.config.ts`, `tests/smoke.test.ts` (or equivalent)
- `AGENTS.md`
- `.env.example`
- `.gitignore` (Next defaults plus `.env`, `.env*.local`)
- `.github/workflows/ci.yml`

## Files to modify

- `README.md` — how to install, `npm test`, `npm run dev`, `npm run build`

## Acceptance criteria

1. [x] `npm ci` then `npm test` exits 0
2. [x] `npm run build` exits 0
3. [x] `npm run dev` serves a page at `/` that includes the word `Atrium`
4. [x] No Tailwind dependency in `package.json`
5. [x] `AGENTS.md` states: Next.js + Neon Postgres + Drizzle; no Express/SQLite; no query without `tenantId` from session; CSS scoped per app; TDD; one feature at a time
6. [x] `.env.example` lists `DATABASE_URL`, `AUTH_SECRET`, `AUTH_OWNER_EMAIL`, `AUTH_OWNER_PASSWORD`, `AUTH_DEMO_EMAIL`, `AUTH_DEMO_PASSWORD` with empty or dummy values
7. [x] `.github/workflows/ci.yml` runs on push and pull_request: Node 22, `npm ci`, `npm test`, `npm run build`
8. [x] No regressions (this is the first code; tree still has the design doc)

## Implementation notes

- Use `create-next-app` or equivalent, then strip Tailwind if the template added it.
- App Router, `app/` at repo root, not `src/app`.
- Do not invent auth or db folders yet.
- Keep the home page boring. Phase 0.4 replaces it with the real launcher behind login.
- Do not add TanStack packages.

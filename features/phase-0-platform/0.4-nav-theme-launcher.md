# Feature 0.4: Nav, theme, and launcher

**Phase:** 0 — Atrium platform
**Status:** pending
**Estimated effort:** 4–5 hours
**Depends on:** 0.3
**Blocks:** 0.5

## Goal

Logged-in users see an Atrium launcher and a shared nav strip with a theme toggle. App routes are placeholders.

## Scope

Include:
- Authenticated layout with nav: Home, CRM, Space, Rolodex, Groove, theme toggle
- Current app marked (amber accent, glyph identity — not a fifth brand color)
- Theme: `data-theme` on `<html>`, `localStorage` key `atrium.theme`, init before first paint, first visit follows OS
- Launcher at `/`: four cards linking to the four apps
- Placeholder pages at `/crm`, `/space`, `/rolodex`, `/groove` (“Coming soon” is enough)
- Signed-in email (or role) visible in the nav
- Nav CSS classes prefixed `atrium-nav-` and self-contained (no shared CSS variables the apps will clash on)

Exclude (for now):
- Reset demo button (0.5)
- Real CRM/Space/Rolodex/Groove UI
- TanStack
- Pixel-identical Bench CSS

## Files to create

- `app/(authenticated)/layout.tsx`
- `app/(authenticated)/page.tsx` — launcher
- `app/(authenticated)/crm/page.tsx`
- `app/(authenticated)/space/page.tsx`
- `app/(authenticated)/rolodex/page.tsx`
- `app/(authenticated)/groove/page.tsx`
- `components/atrium-nav.tsx` (or `lib/` equivalent)
- `components/atrium-nav.module.css` or `app/atrium-nav.css`
- `lib/theme.ts` — `initTheme()`
- tests for theme helper (default, persist, toggle)

## Files to modify

- `app/layout.tsx` — call theme init in a way that avoids a flash (inline script before paint is acceptable)
- `app/page.tsx` — move launcher under the authenticated group; `/` still the launcher
- `e2e/` — smoke: login → see four launcher cards; theme toggle sets `data-theme`

## Acceptance criteria

1. [ ] After login, `/` shows four links: CRM, Space, Rolodex, Groove
2. [ ] Nav is visible on `/` and on `/crm` (and the other app placeholders)
3. [ ] Theme toggle flips `data-theme` between `light` and `dark` and survives reload
4. [ ] First visit without `atrium.theme` follows `prefers-color-scheme`
5. [ ] Nav class names that style the strip are `atrium-nav-` prefixed
6. [ ] `/crm`, `/space`, `/rolodex`, `/groove` render a placeholder, not 404
7. [ ] Unauthenticated users still cannot see the launcher (redirect `/login`)
8. [ ] `npm test` and `npm run build` pass

## Implementation notes

- Groove placeholder is fine as a server component. Web Audio comes in phase 4.
- Do not import CRM/Space/Rolodex/Groove styles into the root layout.
- Amber marks “you are here.” Apps are distinguished by icon/label, not extra brand colors.
